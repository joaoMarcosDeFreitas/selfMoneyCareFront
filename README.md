# Anotações Importantes

---

1. **Comandos React Terminal POWERSHELL:**
    - *npx create-next-app@latest .* -> Cria um projeto React no repositório atual.
    - *npx run dev* -> Roda o projeto React atual.

---

2. **Informações Úteis:** 
    - O arquivo 'Page.tsx' é a página do projeto, é de lá que puxamos nossos outros componentes.
    - Usamos `import` para puxar componentes e outras funcionalidades. 
    - Usamos `export` para indicar ao react que esse componente/função vai ser reutilizada em outro local.
